# Участие в проекте

Опишите проблему, ожидаемое поведение и шаги воспроизведения. Используйте только вымышленные сведения. Не отправляйте реальные вакансии, анкеты, резюме, внутренние документы или настройки доступа.

Перед изменением сделайте копию своих данных вне репозитория. Проверяйте изменения на отдельной пустой папке приложения.

Перед коммитом проверьте список добавляемых файлов и полный diff. Для новых файлов дополните список разрешений в `.gitignore` после проверки содержимого. Не используйте принудительное добавление папки `data`.

Перед отправкой изменений проверьте запуск, вход, создание и сохранение вымышленной карточки, экспорт и повторную загрузку. Для изменений синхронизации проверьте конфликт редактирования одной карточки в двух браузерных сеансах.
