# Безопасность и конфиденциальность

InterviewFlow предназначен для доверенной локальной сети. Встроенный HTTP-сервер не является готовой платформой для размещения в интернете.

- HTTP не шифрует трафик, а локальные файлы не зашифрованы приложением.
- Используется общий код доступа без ролей, индивидуальных пользователей и журнала действий.
- Анкеты, настройки доступа, резервные копии и отчёты не должны попадать в Git.
- Не прикладывайте реальные анкеты, коды доступа и содержимое `data` к issues, обсуждениям или скриншотам.

При обнаружении уязвимости не публикуйте секреты и данные кандидатов. До публикации проекта владелец должен определить закрытый канал сообщений об уязвимостях. Такой канал пока не настроен.
