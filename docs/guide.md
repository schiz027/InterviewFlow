InterviewFlow — небольшое браузерное приложение для проведения собеседований на своём компьютере или в доверенной локальной сети. Карточка кандидата, вопросы, наблюдения и итог собраны в одном месте. Оценки и решение принимает интервьюер.

## Возможности

- Карточки кандидатов, поиск и статусы.
- Несколько вакансий с отдельными списками кандидатов и редактором вопросов и критериев.
- Вопросы в разделах «Знакомство» и «Профильные вопросы»: публичная версия содержит нейтральные примеры, которые можно заменить под свои задачи.
- Ответы, личные заметки, пропуск вопросов и оценки с обоснованием.
- Автосохранение и уведомление о конфликте при одновременном изменении одной карточки.
- Полный или краткий отчёт в DOCX и TXT, печать A4 и сохранение PDF через браузер.
- Резервные копии JSON и восстановление карточек.
- Светлая и тёмная темы, адаптивный интерфейс.

## Быстрый запуск

Нужны Python 3.10+ и современный браузер. Внешние Python-пакеты не требуются.

1. Скачайте исходники и распакуйте их в доступную для записи папку.
2. В Windows откройте `Запустить.cmd`. Или запустите из папки проекта:

   ```sh
   python server.py
   ```

3. Откройте адрес из окна запуска, обычно `http://127.0.0.1:8760`.
4. Введите PIN-код из того же окна.

При первом запуске приложение создаёт папку `data`. Закрытие окна сервера останавливает приложение. Перед выходом дождитесь сообщения о сохранении.

## Работа в локальной сети

Запустите сервер на одном компьютере. На остальных откройте показанный им сетевой адрес и введите PIN-код. При необходимости разрешите входящие подключения Python в брандмауэре для доверенной частной сети. Приложение не меняет настройки брандмауэра самостоятельно.

Вход использует PIN из четырёх цифр с ограничением попыток. Сервер слушает все сетевые интерфейсы (`0.0.0.0`). HTTP-соединение не шифруется. Не открывайте порт в интернет и не используйте приложение в недоверенной сети. Общий PIN-код не заменяет индивидуальные учётные записи и разграничение прав: вошедшие пользователи имеют доступ ко всем анкетам.

## Где хранятся данные

| Файл | Содержимое |
| --- | --- |
| `data/vacancies.json` | Вакансии, вопросы и критерии оценки |
| `data/candidates.json` | Карточки, ответы, заметки и оценки |
| `data/network.json` | Порт и PIN-код |
| `data/server.lock` | Блокировка повторного запуска |

Данные хранятся на компьютере с сервером. В коде нет отправки анкет во внешние сервисы. Файлы данных не зашифрованы приложением: ограничьте доступ к папке средствами операционной системы.

Резервные копии и отчёты могут содержать персональные данные. Храните их отдельно от исходников. Краткий отчёт исключает внутренние наблюдения, оценки и итоговый отзыв, но содержит сведения кандидата и ответы.

Для смены порта или кода остановите сервер, измените `data/network.json` и запустите снова. Вход действует до 12 часов; перезапуск сервера завершает текущие сеансы.

## Одновременное редактирование и резервные копии

Разные карточки можно редактировать одновременно. Если одну карточку уже изменили, приложение сообщит о конфликте. Скачайте резервную копию несохранённых ответов, обновите список и перенесите нужные изменения вручную.

Перед общей резервной копией сохраните изменения и нажмите «Обновить список». Восстановление добавляет карточки из копии и заменяет карточки с совпадающими идентификаторами. До восстановления сделайте отдельную копию текущих данных.

## Устройство проекта

```text
server.py       HTTP-сервер, хранение данных, вход и DOCX
index.html      Интерфейс, вопросы, заметки и отчёты
Запустить.cmd   Запуск в Windows
docs/           Публичные материалы проекта
```

Вакансии, вопросы и критерии редактируются в интерфейсе и сохраняются в `data/vacancies.json`. Вакансии можно добавлять, переставлять и удалять вместе с их кандидатами после двух подтверждений. Резервная копия версии 2 содержит и вакансии, и анкеты. Публичный стартовый шаблон — `default-template.json`; при наличии локального `default-vacancy.json` используется он. Локальный шаблон исключён из Git. Не заменяйте идентификаторы вопросов с уже записанными ответами без проверки последствий.
